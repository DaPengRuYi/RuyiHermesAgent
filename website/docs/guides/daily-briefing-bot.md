# 教程：构建每日简报机器人

在本教程中，你将构建一个个人简报机器人，每天早上醒来，研究你关心的主题，总结发现，并将简洁的简报直接投递到你的 Telegram 或 Discord。

最终，你将拥有一个完全自动化的工作流，结合**网络搜索**、**cron 调度**、**委托**和**消息投递** — 无需编码。

## 我们在构建什么

流程如下：

1. **上午 8:00** — Cron 调度器触发你的作业
2. **Hermes 启动**一个带有你提示的新代理会话
3. **网络搜索**拉取你主题的最新新闻
4. **总结**将其提炼为干净的简报格式
5. **投递**将简报发送到你的 Telegram 或 Discord

整个过程免手动操作。你只需在喝早咖啡时阅读简报。

## 前提条件

开始前，确保你有：

- **Hermes Agent 已安装** — 参见[安装指南](/docs/getting-started/installation)
- **网关在运行** — 网关守护进程处理 cron 执行：
  ```bash
  hermes gateway install   # 安装为用户服务
  sudo hermes gateway install --system   # Linux 服务器：启动时系统服务
  # 或
  hermes gateway           # 在前台运行
  ```
- **Firecrawl API 密钥** — 在环境中设置 `FIRECRAWL_API_KEY` 用于网络搜索
- **消息已配置**（可选但推荐） — [Telegram](/docs/user-guide/messaging/telegram) 或 Discord 设置了主频道

:::tip 没有消息平台？没问题
你仍然可以使用 `deliver: "local"` 跟随本教程。简报将保存到 `~/.hermes/cron/output/`，你可以随时阅读。
:::

## 步骤 1：手动测试工作流

在自动化之前，让我们确保简报有效。启动聊天会话：

```bash
hermes
```

然后输入此提示：

```
搜索关于 AI 代理和开源 LLM 的最新新闻。
总结前 3 条故事为简洁的简报格式，包含链接。
```

Hermes 将搜索网络，阅读结果，并生成类似这样的内容：

```
☀️ 你的 AI 简报 — 2026 年 3 月 8 日

1. Qwen 3 发布，拥有 2350 亿参数
   阿里最新的开放权重模型在多个基准测试中匹配 GPT-4.5，
   同时保持完全开源。
   → https://qwenlm.github.io/blog/qwen3/

2. LangChain 推出代理协议标准
   一个新的代理对代理通信开放标准在第一周就获得了
   15 个主要框架的采用。
   → https://blog.langchain.dev/agent-protocol/

3. EU AI Act 对通用模型开始执行
   第一批合规截止日期到来，开源模型在 1000 万参数
   阈值下获得豁免。
   → https://artificialintelligenceact.eu/updates/

---
3 条故事 • 搜索来源：8 • 由 Hermes Agent 生成
```

如果这有效，你就可以自动化了。

:::tip 迭代格式
尝试不同的提示直到你获得喜欢的输出。添加指令如 "使用 emoji 标题" 或 "每个摘要保持在 2 句以内。" 你最终决定的内容会进入 cron 作业。
:::

## 步骤 2：创建 Cron 作业

现在让我们安排这个每天早上自动运行。你可以通过两种方式完成。

创建 cron 作业前，确保 Hermes 全局配置了默认模型和提供者。如果你希望特定作业使用不同的值，在创建时设置显式的每作业模型/提供者覆盖。

### 选项 A：自然语言（在聊天中）

直接告诉 Hermes 你想要什么：

```
每天早上 8 点，搜索关于 AI 代理和开源 LLM 的最新新闻。
总结前 3 条故事为带链接的简洁简报。
使用友好、专业的语气。投递到 telegram。
```

Hermes 将使用统一的 `cronjob` 工具为你创建 cron 作业。

### 选项 B：CLI 斜杠命令

使用 `/cron` 命令获得更多控制：

```
/cron add "0 8 * * *" "搜索关于 AI 代理和开源 LLM 的最新新闻。查找过去 24 小时内至少 5 篇最近的文章。总结前 3 条最重要的故事为简洁的每日简报格式。每条故事包含：清晰的标题、2 句摘要和来源 URL。使用友好、专业的语气。使用 emoji 要点格式化，以总故事数结尾。"
```

### 黄金法则：自包含提示

:::warning 关键概念
Cron 作业在**完全全新的会话**中运行 — 没有你之前对话的记忆，没有你 "之前设置的" 上下文。你的提示必须包含代理完成工作所需的**一切**。
:::

**糟糕的提示：**
```
做我通常的早间简报。
```

**好的提示：**
```
搜索关于 AI 代理和开源 LLM 的最新新闻。
查找过去 24 小时内至少 5 篇最近的文章。总结前 3 条
最重要的故事为简洁的每日简报格式。每条故事包含：
清晰的标题、2 句摘要和来源 URL。使用友好、专业的语气。
使用 emoji 要点格式化。
```

好的提示在**搜索什么**、**多少文章**、**什么格式**和**什么语气**方面是具体的。它是代理一次性需要的一切。

## 步骤 3：自定义简报

一旦基本简报工作了，你可以发挥创意。

### 多主题简报

在一个简报中覆盖多个领域：

```
/cron add "0 8 * * *" "创建一个涵盖三个主题的早间简报。对每个主题，搜索过去 24 小时的最近新闻并总结前 2 条故事，包含链接。

主题：
1. AI 和机器学习 — 关注开源模型和代理框架
2. 加密货币 — 关注比特币、以太坊和监管新闻
3. 太空探索 — 关注 SpaceX、NASA 和商业太空

格式化为带有章节标题和 emoji 的干净简报。以今天的日期和励志名言结尾。"
```

### 使用委托进行并行研究

要获得更快的简报，告诉 Hermes 将每个主题委托给子代理：

```
/cron add "0 8 * * *" "通过委托研究给子代理创建早间简报。委托三个并行任务：

1. 委托：搜索过去 24 小时的前 2 条 AI/ML 新闻故事，包含链接
2. 委托：搜索过去 24 小时的前 2 条加密货币新闻故事，包含链接
3. 委托：搜索过去 24 小时的前 2 条太空探索新闻故事，包含链接

收集所有结果并将它们组合成一个带有章节标题、emoji 格式和来源链接的干净简报。添加今天的日期作为标题。"
```

每个子代理独立并行搜索，然后主代理将所有内容组合成一个精美的简报。有关工作原理的更多信息，请参见[委托文档](/docs/user-guide/features/delegation)。

### 仅工作日调度

周末不需要简报？使用针对周一至周五的 cron 表达式：

```
/cron add "0 8 * * 1-5" "搜索最新的 AI 和科技新闻..."
```

### 每日两次简报

获得早间概述和晚间回顾：

```
/cron add "0 8 * * *" "早间简报：搜索过去 12 小时的 AI 新闻..."
/cron add "0 18 * * *" "晚间回顾：搜索过去 12 小时的 AI 新闻..."
```

### 使用记忆添加个人上下文

如果你启用了[记忆](/docs/user-guide/features/memory)，你可以存储跨会话持久化的偏好。但记住 — cron 作业在没有对话记忆的新会话中运行。要添加个人上下文，直接将其烘焙到提示中：

```
/cron add "0 8 * * *" "你正在为一位关心以下内容的资深 ML 工程师创建简报：PyTorch 生态系统、transformer 架构、开放权重模型和欧盟的 AI 监管。跳过关于产品发布或融资轮的故事，除非它们涉及开源。

搜索这些主题的最新新闻。总结前 3 条故事，包含链接。简洁且技术性 — 这位读者不需要基础解释。"
```

:::tip 定制角色
包含关于简报是为谁准备的细节会显著提高相关性。告诉代理你的角色、兴趣和要跳过的内容。
:::

## 步骤 4：管理你的作业

### 列出所有定时作业

在聊天中：
```
/cron list
```

或从终端：
```bash
hermes cron list
```

你会看到类似这样的输出：

```
ID          | 名称              | 调度        | 下次运行           | 投递
------------|-------------------|-------------|--------------------|--------
a1b2c3d4    | 早间简报          | 0 8 * * *   | 2026-03-09 08:00   | telegram
e5f6g7h8    | 晚间回顾          | 0 18 * * *  | 2026-03-08 18:00   | telegram
```

### 移除作业

在聊天中：
```
/cron remove a1b2c3d4
```

或对话式地问：
```
移除我的早间简报 cron 作业。
```

Hermes 将使用 `cronjob(action="list")` 查找它并使用 `cronjob(action="remove")` 删除它。

### 检查网关状态

确保调度器确实在运行：

```bash
hermes cron status
```

如果网关没有运行，你的作业不会执行。将其安装为后台服务以获得可靠性：

```bash
hermes gateway install
# 或在 Linux 服务器上
sudo hermes gateway install --system
```
